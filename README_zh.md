# Delphi Pipeline

[English](README.md) | [中文](README_zh.md)

这个仓库实现了**Delphi管道**，旨在通过迭代式的专家意见征集来聚合专家意见，利用大型语言模型（LLMs）。这个实现集成了概率推理、情景分析和贝叶斯更新，以支持复杂决策的共识构建。

## 功能

- **基于LLM的专家模拟**：使用GPT模型模拟专家预测。
- **自动轮次管理**：动态管理专家征集和反馈的轮次。
- **概率聚合**：基于专家分散度计算加权平均概率。
- **Metaculus集成**：获取已解决的二元问题和人类预测以进行比较分析。
- **交互式可视化**：生成洞察性图表以分析共识、校准和变异性。
- **贝叶斯可信区间**：构建后验分布以进行稳健的概率推理。

## 使用案例

- **AI风险评估**：评估AI治理情景中关键结果的可能性。
- **预测**：使用结构化概率方法预测趋势和事件。
- **政策制定**：聚合专家输入以告知治理和监管策略。
- **研究**：研究专家预测与基于LLM的预测的可靠性和校准。

- `openai`
- `httpx`
- `requests`
- `numpy`
- `pandas`
- `scipy`
- `seaborn`
- `matplotlib`

### 安装

1. 克隆仓库：

```bash
git clone https://github.com/your-username/DelhiLM.git
cd DelhiLM
```

2. 设置环境变量以获取API密钥（例如，OpenAI，Metaculus）：

```bash
export OPENAI_API_KEY="your-api-key"
export METACULUS_API_URL="your-api-url"
```

## 工作流程

1. **情景准备**：从Metaculus格式化和提取已解决的二元问题。
2. **Delphi征集**：
   - 查询LLMs和/或人类专家以获取概率估计。
   - 聚合响应并提供匿名反馈。
   - 重复直到达到共识（由标准差阈值定义）。
3. **分析**：
   - 将征集的概率与人类预测进行比较。
   - 计算校准指标（例如，Brier分数）。
   - 绘制变异性和贝叶斯可信区间。
4. **结果可视化**：可视化关键指标，包括Brier分数和正确与错误预测的变异性。

## 笔记本结构...

笔记本`Delphi_LLMs.ipynb`包括以下内容：

- **数据准备**：从Metaculus获取和处理情景。
- **征集逻辑**：实现LLMs的多轮查询与自适应反馈。
- **统计分析**：计算加权平均值、标准差和贝叶斯更新。
- **可视化**：生成校准、变异性和情景分布的图表。

## 关键函数

- `delphi_process_single_scenario`：管理单个情景的Delphi过程，迭代查询专家直到共识。
- `calculate_weighted_mean`：计算由专家响应分散度加权的聚合概率。
- `plot_variability_correct_incorrect`：比较正确与错误结果预测的变异性。
- `construct_bayesian_intervals`：使用Beta分布生成可信区间。

## 配置

在笔记本或配置文件中调整参数以自定义：
- 专家和轮次数。
- 共识标准差阈值。
- 贝叶斯先验参数。

## 结果

管道输出：
- 聚合概率及其分布。
- 校准指标（例如，Brier分数）
- LLM与人类预测的比较分析
- 决策洞察的可视化。
